# Evaluation Rubric

## Completeness (40%)
- Does the implementation meet all functional requirements listed in the prompt?
- Are all required elements present (e.g., specific fields, buttons, states)?

## Visual Fidelity (30%)
- Does the result look like a cohesive part of the design system?
- Are spacing, typography, and colors consistent with the system's defaults?

## Code Quality (20%)
- Is the code clean and readable?
- Are the correct design system components used (vs. custom CSS/HTML)?
- Is the component structure logical?

## Efficiency (10%)
- Time taken to complete the task (measured via logs).
