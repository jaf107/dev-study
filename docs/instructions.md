# Developer Study Instructions

## Purpose
This study explores how developers use design systems to build common UI components. You will complete 5 short tasks using a specific design system.

## How to Run
1.  **Install dependencies:**
    \`\`\`bash
    pnpm install
    \`\`\`
2.  **Start the development server:**
    \`\`\`bash
    pnpm dev
    \`\`\`
3.  **Open the app:** Go to \`http://localhost:5173\` (or the URL shown in the terminal).

## Design System Assignment
You have been assigned one of the following design systems: **Material UI**, **Carbon Design System**, or **Fluent UI**.

**Before starting Task 1:**
1.  Open \`src/main.tsx\`.
2.  Uncomment the \`Provider\` and imports for your **assigned design system**.
3.  Ensure the app reloads without errors.

## Logging Your Time
For **each task**, you must log your start and end times.

**Start a task:**
\`\`\`bash
pnpm log:start task-1
\`\`\`

**End a task:**
\`\`\`bash
pnpm log:end task-1
\`\`\`

*Replace \`task-1\` with the appropriate task ID (task-2, task-3, etc.).*

## Submission
When you have completed all 5 tasks:
1.  Ensure all code is saved.
2.  Zip the entire project folder (excluding \`node_modules\`) or push to the provided repository.
3.  Fill out the Post-Task Survey (see \`docs/post-task-survey.md\`).
